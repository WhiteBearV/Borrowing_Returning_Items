  ── DATABASE ──────────────────────────────────────────────────────────────────

  DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/equipment_borrow

    postgresql+asyncpg://  → ไดรเวอร์ที่ใช้ (asyncpg = async PostgreSQL)
    user:password          → ชื่อ user และรหัสผ่าน PostgreSQL
    localhost:5432         → host และ port ของ database server
                             (ถ้ารันผ่าน Docker Compose ให้เปลี่ยน localhost → db)
    equipment_borrow       → ชื่อ database (Docker Compose จะสร้างให้อัตโนมัติ)

    ✏️  ต้องแก้: user, password ให้ตรงกับที่ตั้งใน PostgreSQL หรือ docker-compose.yml


  ── JWT (ระบบ login / token) ──────────────────────────────────────────────────

  SECRET_KEY=your-secret-key-here-change-in-production

    ใช้เซ็น JWT token ทุกอัน ถ้าใครรู้ค่านี้ = สามารถปลอม token เข้าระบบได้ทุก account
    ✏️  ต้องแก้: สร้าง random key ด้วยคำสั่ง:
        python -c "import secrets; print(secrets.token_hex(32))"

  ALGORITHM=HS256
    อัลกอริทึมเซ็น token → ไม่ต้องแก้

  ACCESS_TOKEN_EXPIRE_MINUTES=30
    token หมดอายุใน 30 นาที → login ใหม่ หรือใช้ refresh token
    ปรับได้ตามต้องการ เช่น 60 (1 ชั่วโมง) หรือ 480 (8 ชั่วโมง)

  REFRESH_TOKEN_EXPIRE_DAYS=7
    refresh token (ใช้ขอ access token ใหม่โดยไม่ต้อง login ซ้ำ) หมดอายุใน 7 วัน
    ปรับได้ตามต้องการ


  ── EMAIL (ใช้ส่ง verify email และ reset password) ───────────────────────────

  MAIL_USERNAME=your-email@example.com
    Gmail ที่ใช้เป็นตัวส่งอีเมล
    ✏️  ต้องแก้: ใส่ Gmail จริง เช่น borrowsystem@gmail.com

  MAIL_PASSWORD=your-app-password
    ⚠️  ไม่ใช่รหัสผ่าน Gmail ปกติ! ต้องใช้ "App Password" เท่านั้น
    วิธีสร้าง App Password:
      1. เปิด myaccount.google.com → Security
      2. เปิด 2-Step Verification (ถ้ายังไม่ได้เปิด)
      3. ค้นหา "App passwords" → เลือก Other → ตั้งชื่อ → Generate
      4. จะได้รหัส 16 ตัว เช่น "abcd efgh ijkl mnop" → ใส่โดยไม่มีช่องว่าง
    ✏️  ต้องแก้: ใส่ App Password 16 ตัวที่ได้

  MAIL_FROM=your-email@example.com
    ชื่อ/อีเมลที่ปรากฏในกล่องจดหมายของผู้รับ
    ✏️  ต้องแก้: ใส่เหมือน MAIL_USERNAME

  MAIL_PORT=587
  MAIL_SERVER=smtp.gmail.com
  MAIL_STARTTLS=true
  MAIL_SSL_TLS=false
    การตั้งค่า SMTP ของ Gmail → ไม่ต้องแก้


  ── APP URLs ──────────────────────────────────────────────────────────────────

  APP_BASE_URL=http://localhost:8000
    URL ของ backend — ใช้สร้าง link ใน email เช่น
    "คลิกที่นี่เพื่อยืนยัน email: http://localhost:8000/verify?token=..."
    ✏️  ไม่ต้องแก้ตอน dev / ต้องแก้เป็น domain จริงตอน deploy บนเซิร์ฟเวอร์

  FRONTEND_URL=http://localhost:5173
    URL ของ frontend — ใช้ตั้ง CORS และสร้าง link กลับไปหน้าเว็บ
    ✏️  ไม่ต้องแก้ตอน dev / ต้องแก้ตอน deploy

  UPLOAD_DIR=./uploads
    โฟลเดอร์เก็บไฟล์รูป (รูปอุปกรณ์, รูปความเสียหาย)
    → ไม่ต้องแก้ ระบบสร้างให้อัตโนมัติตอนเริ่ม


  ── EMAIL DOMAIN ──────────────────────────────────────────────────────────────

  ALLOWED_EMAIL_DOMAINS=cdti.ac.th,student.cdti.ac.th

    ป้องกันคนนอกสถาบันสมัครสมาชิก
    มีแค่ email ที่ลงท้ายด้วย domain เหล่านี้เท่านั้นที่สมัครได้

    ถ้าอยากทดสอบด้วย Gmail ก่อน:
    ALLOWED_EMAIL_DOMAINS=gmail.com,cdti.ac.th,student.cdti.ac.th

  ขั้นตอนที่ 2: login เป็นแอดมิน
    → ต้องสร้าง admin user ใน DB โดยตรงก่อน (หรือเขียน seed script)

    → ตรวจว่า stock กลับคืน และสถานะเป็น completed

## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend
- แก้ bug `users_service.py::delete_user()` — FK constraint จาก `auth_tokens_user_id_fkey` ทำให้ลบ user ไม่ได้ แก้โดยเพิ่ม `DELETE FROM auth_tokens WHERE user_id = ?` ก่อนลบ user
- เพิ่ม cascade delete `auth_tokens` ก่อน user ใน `services/users_service.py`

### Frontend
- แก้ `UsersPage.jsx` — เพิ่ม try/catch รอบ `deleteUser()` เพื่อแสดง error แทนที่จะ silent fail
- แก้ image URL ใน `EquipmentListPage.jsx` และ `EquipmentDetailPage.jsx` — เติม base URL (`http://localhost:8000`) เมื่อ path ขึ้นต้นด้วย `/` เพื่อให้รูปโหลดจาก FastAPI แทน Vite
- เพิ่ม `Pagination` component ใหม่ (`components/common/Pagination.jsx`) รองรับ: กระโดด ±5 หน้า, dropdown เลือกหน้า, ปุ่มก่อนหน้า/ถัดไป
- ใช้ `<Pagination>` แทน pagination เดิมใน 7 หน้า: `EquipmentListPage`, `MyBorrowsPage`, `AllBorrowsPage`, `BorrowRequestsPage`, `UsersPage`, `AuditLogPage`, `EquipmentManagePage`

### อื่น ๆ (Data, Docs)
- SSH เข้า Snipe-IT server (ton@172.16.46.64) และ SCP รูปอุปกรณ์ 105 ไฟล์มาเก็บที่ `backend/uploads/equipment/`
- Query MySQL ใน Snipe-IT เพื่อ map `asset_tag → image` แล้ว UPDATE ตาราง `equipment` ทั้งหมด 1,006 รายการ
- NULL image_url 37 รายการที่ไฟล์รูปหายจาก Snipe-IT server (Dell Optiplex และอื่น ๆ)
- ลบข้อมูล test จาก pytest ที่หลุดเข้า production DB: 3 หมวดหมู่ "หมวดทดสอบ_xxx" พร้อม equipment และ borrow_items ที่เกี่ยวข้อง
- ลบ test user "นายสมเดจ เกจเวย์" ที่ค้างอยู่ใน DB
- สร้างเอกสาร PDF บันทึกการปรึกษา (`Report/บันทึกการปรึกษา_2026-06-30.pdf`) ด้วย ReportLab + Garuda font (Thai+Latin) จาก 9 ประเด็นที่คุยกับอาจารย์

## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend
- `services/users_service.py::list_users()` + `routers/users.py` — เพิ่มพารามิเตอร์ `q` ค้นหาผู้ใช้จาก ชื่อ / รหัสนักศึกษา /
  รหัสบุคลากร (username) / อีเมล (ILIKE บางส่วน ไม่สนตัวพิมพ์, จำกัด 100 ตัวอักษร)
- `list_users()` — แก้บั๊กเดิม: ไม่มี ORDER BY เลย แบ่งหน้าแล้วแถวซ้ำ/หายได้ (ผิดกฎ "ทุก list ที่แบ่งหน้าต้อง ORDER BY
  จบด้วยคอลัมน์ unique" ใน CLAUDE.md) → เรียง `created_at desc, id`
- `services/system_check_service.py::run_checks()` — ทุกเรื่องใน "ข้อมูลที่ควรตรวจสอบ" มี `sample` (รหัสอุปกรณ์ /
  เลขคำขอ / อีเมล ไม่เกิน 5) + `link` (หน้าที่ใช้แก้) · รวม helper `sample_of()` / `count_of()` ลดโค้ดซ้ำ
- แก้บั๊กเตือนหลอก "รายการยืมค้างที่อุปกรณ์ถูกลบไปแล้ว" — เดิมนับรายการในคำขอที่ถูกปฏิเสธ (returned=False ค้างตลอดไป)
  เจอจากข้อมูล Prod จริง 6 ชิ้นเป็นคำขอ rejected ทั้งหมด → นับเฉพาะคำขอ approved + ชิ้นที่ไม่ถูกปฏิเสธ
- `tests/test_user_search.py` (ใหม่) — ค้นด้วยชื่อ/รหัส/อีเมล + ไม่เจอ = 0 · cleanup user และ audit_logs ใน finally
- pytest 508/508 ผ่าน (รันบนฐานข้อมูลที่ sync จาก Prod)

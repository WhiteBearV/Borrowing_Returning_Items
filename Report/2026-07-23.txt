## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend

- **ยกเว้นลิมิตการยืมให้ admin** — `app/services/borrow_service.py::create_request`
  เพิ่มตัวแปร `is_admin = current_user.role == "admin"` แล้วข้ามการเช็ค
  `max_active_requests_per_student` และ `max_items_per_request` เมื่อเป็น admin
  (นักศึกษายังติดลิมิตเดิมทุกประการ) — แก้อาการอาจารย์/แอดมินยืมของเกิน 5 รายการไม่ได้

- **ใบคืนแบบสะสม + คอลัมน์วัน-เวลาที่คืน** — `app/utils/pdf.py::_build_form` (สาขา return)
  กรองรายการให้เหลือเฉพาะ `item.returned == True` เรียงตาม `returned_at`
  และเพิ่มคอลัมน์ "วันเวลาที่คืน" ในตาราง (ใบคืน = 7 คอลัมน์, ใบยืม = 6 คอลัมน์เท่าเดิม)
  ผลลัพธ์: คืนทีละชิ้น = ใบเดิมโตทีละแถว แต่ละแถวปั๊มเวลาคืนของตัวเอง
  ตรงตาม Business Rule เรื่องการคืน/สรุปผลใน CLAUDE.md (returned_at มีต่อชิ้นอยู่แล้ว ไม่ต้อง migration)

- **ยืมเป็นชุดผูกกับอุปกรณ์ (bundle trigger)**
  - `app/models/bundle.py` — เพิ่มคอลัมน์ `trigger_equipment_id` (FK→equipment, ON DELETE SET NULL)
    + relationship `trigger_equipment` + property `trigger_equipment_name` (จับคู่ตามชื่อรุ่น)
  - `app/schemas/bundle.py` — เพิ่ม `trigger_equipment_id` ใน Create/Update/Response
    และ `trigger_equipment_name` ใน Response
  - `app/services/bundle_service.py` — create/update บันทึก trigger, eager-load `trigger_equipment`
    ใน `_load` และ `list_bundles` (กัน lazy-load พังใต้ async)
  - Migration ใหม่ `alembic/versions/0014_bundle_trigger.py` (0013 → 0014)

- **สคริปต์ seed ของที่ขาด + ชุดจริง** — `scripts/seed_desktop_bundle.py` (idempotent, รันซ้ำได้)
  - สร้าง material 3 รายการ: `ACC-MOUSE-001` เมาส์ USB, `ACC-KEYBOARD-001` คีย์บอร์ด USB,
    `ACC-PWR-001` สายไฟ AC คอมพิวเตอร์ (Power Cord) — อย่างละ 40 ชิ้น
  - สร้างชุด "ชุดคอมพิวเตอร์ตั้งโต๊ะ Dell Optiplex 7040 (อุปกรณ์ต่อพ่วง)"
    trigger = คอมตั้งโต๊ะ, items = เมาส์ + คีย์บอร์ด + สายไฟ

### Frontend

- **ปุ่มดูใบรับคืนโผล่ตั้งแต่คืนบางส่วน** — `pages/admin/AllBorrowsPage.jsx`
  เปลี่ยนเงื่อนไขจาก `req.status === 'completed'` เป็น `req.items?.some(i => i.returned)`

- **แก้ปุ่มอนุมัติ/ปฏิเสธเงียบ** — `pages/admin/BorrowRequestsPage.jsx`
  เดิม `approve`/`reject` ไม่มี try/catch → error โดนกลืน หน้าจอเงียบ เหมือน "กดไม่ติด"
  เพิ่ม state `actionError` + try/catch + แถบ error สีแดง แสดง `error.response.data.detail`

- **ซ่อนเมนู "คำขอของฉัน" จากแอดมิน** — `components/layout/Sidebar.jsx`
  เอา `/my-borrows` ออกจาก `ADMIN_NAV` (แอดมินดูคำขอตัวเองใน "ประวัติการยืม" ได้อยู่แล้ว)

- **เพิ่ม auto-expand ชุดตอนกดเพิ่มลงตะกร้า** — `pages/student/EquipmentListPage.jsx`
  และ `pages/student/EquipmentDetailPage.jsx`
  จับคู่ชุดด้วย `trigger_equipment_id === id || trigger_equipment_name === eq.name`
  (ครอบคอมตั้งโต๊ะทั้ง 40 เครื่องด้วยชุดเดียว) แล้วเพิ่มยูนิตที่กด + อุปกรณ์ต่อพ่วงในชุด

- **เพิ่มตัวเลือก "อุปกรณ์ตัวกระตุ้น" ในฟอร์มชุด** — `pages/admin/BundleManagePage.jsx`
  dropdown เลือก trigger จากรายการในชุด + แก้ `toggleActive` ให้ส่ง trigger เดิมไปด้วย
  (เพราะ backend เขียนทับ trigger ทุกครั้งที่ update)

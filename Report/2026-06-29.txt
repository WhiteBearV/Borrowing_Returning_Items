## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend

**แก้ไข Bug**
- `app/services/borrow_service.py` — `list_requests()`: เพิ่ม `selectinload(BorrowRequest.student)` ที่ขาดหายไป
  - Root cause: ฟังก์ชันไม่ได้ eager load student relationship → Pydantic serialize `student_name` ไม่ได้ → 500 error → frontend แสดงรายการว่าง ทั้งที่ DB มีข้อมูล 6 pending requests

**เพิ่ม Endpoint ใหม่**
- `DELETE /equipment/{id}/permanent` (`app/routers/equipment.py`) — ลบอุปกรณ์ถาวร (admin only)
  - Service: `equipment_service.delete_equipment()` — เช็ค `status == 'retired'` และไม่มี borrow_items อ้างอิงก่อนลบ
- `DELETE /borrow-requests/{id}` (`app/routers/borrow.py`) — ลบประวัติการยืม (admin only)
  - Service: `borrow_service.delete_request()` — อนุญาตเฉพาะ status: completed / rejected / cancelled
  - Cascade: ลบ Notification → BorrowItem → BorrowRequest ตามลำดับ FK
- `DELETE /users/{id}` (`app/routers/users.py`) — ลบ user ถาวร (admin only, ต้อง is_active=False ก่อน)
  - Service: `users_service.delete_user()` — cascade ลบ notifications + borrow history ทั้งหมด

**แก้ไข Cascade Bug ใน Test Teardown**
- `app/services/users_service.py` — import `delete, BorrowItem, BorrowRequest, Notification`

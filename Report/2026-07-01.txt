## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend
- **แก้ test login ที่ล้มเหลว 3 เคส** (`tests/test_api_integration.py`) — schema `LoginRequest` เปลี่ยนไปใช้ field `identifier` (รองรับ login ด้วย student_id / username / email) แต่ test ยังส่ง key `"email"` อยู่ ทำให้คืน 422 แทน 200/401/403 แก้เป็น `identifier` ครบทั้ง 3 จุด
- **เพิ่มฟีเจอร์ "ผู้ครอบครองอุปกรณ์ในขณะนั้น"** ตาม proposal ข้อ 3.1 (ฝั่งนักศึกษา):
  - `schemas/equipment.py` — เพิ่ม `HolderInfo` + `EquipmentDetailResponse`
  - `services/equipment_service.py` — เพิ่ม `get_holders()` query หา borrow ที่ `returned=False` และ request `status=approved` join ชื่อผู้ยืม + กำหนดคืน (ใช้ `extended_due_date` ก่อนถ้ามีต่อเวลา)
  - `routers/equipment.py` — endpoint รายละเอียดอุปกรณ์คืน holders ด้วย
- **เปลี่ยนความสัมพันธ์ Equipment ↔ Category เป็น many-to-many** (อุปกรณ์ 1 ชิ้นอยู่ได้หลายหมวดพร้อมกัน เช่น สายไฟ = Electronic + วัสดุ):
  - `models/equipment.py` — เพิ่มตารางเชื่อม `equipment_category_links`, เปลี่ยน `category_id` (FK เดี่ยว) → `categories` (relationship M2M)
  - `models/equipment_category.py` — `equipment` relationship ใช้ secondary table
  - `schemas/equipment.py` — response คืน `categories: list`, create/update รับ `category_ids: list`
  - `services/equipment_service.py` — filter หมวดผ่าน join, eager-load `selectinload(Equipment.categories)`, เพิ่ม `_resolve_categories()` ตรวจ id หมวดว่ามีจริง, แก้ create/update ให้ set categories
  - `alembic/versions/0004_equipment_categories_m2m.py` — migration สร้างตารางเชื่อม + ย้ายข้อมูลเดิม (1104 ชิ้น) + drop คอลัมน์เดิม (upgrade แล้ว)
  - `scripts/import_equipment.py` — แก้ให้ emit INSERT ลงตารางเชื่อมแทน category_id (กันพังถ้า re-run)
- **เพิ่ม/แก้ tests** — เพิ่ม `test_equipment_multiple_categories` (create อุปกรณ์ 2 หมวด + filter), แก้ `conftest.py` fixture ให้ใช้ `categories=[cat]` และ re-fetch category ใน session เดียวกัน
- ผลรวม: **50 tests ผ่านทั้งหมด**

### Frontend
- **หน้า Login** (`pages/LoginPage.jsx`) — ลบ tab นักศึกษา/ผู้ดูแลระบบออก เหลือ 2 ช่อง (รหัสประจำตัว + รหัสผ่าน) ให้ระบบ auto-detect role เอง (backend match identifier แล้วส่ง role กลับ, redirect ตาม `user.role`)
- **แสดงจำนวนคงเหลือให้ยืม + สถานะถูกยืม**:
  - `pages/student/EquipmentListPage.jsx` — ทุกชิ้นโชว์ "เหลือให้ยืม: X ชิ้น" ถ้ายืมไม่ได้ขึ้นข้อความแดงบอกเหตุผลจริง (ถูกยืมอยู่ / หมด / ซ่อม / เสียหาย) + เพิ่ม helper `unavailableReason()`
  - `pages/student/EquipmentDetailPage.jsx` — เพิ่มแถว "เหลือให้ยืม" ให้ครุภัณฑ์ด้วย + แบนเนอร์แดงเมื่อยืมไม่ได้ + กล่อง "ผู้ครอบครองในขณะนี้" (ชื่อ + จำนวน + กำหนดคืน) + แถว "หมวดหมู่"
- **รองรับหลายหมวดในหน้า admin** (`pages/admin/EquipmentManagePage.jsx`) — เปลี่ยน select หมวดเดี่ยวเป็น chip เลือกได้หลายหมวด (`toggleCategory`), บังคับเลือกอย่างน้อย 1 หมวด, เพิ่มคอลัมน์ "หมวดหมู่" ในตารางจัดการ, แก้ payload ให้ส่ง `category_ids`
- Frontend build ผ่านไม่มี error

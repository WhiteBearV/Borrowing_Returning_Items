## สิ่งที่ทำสำเร็จวันนี้ ✅

### Backend

**Alembic Migrations (ใหม่ทั้งหมด)**
- `alembic/versions/0001_initial_schema.py` — สร้างตารางทั้ง 9 ตาราง พร้อม index ครบ
  (users, auth_tokens, equipment_categories, equipment, borrow_requests, borrow_items, notifications, audit_logs, settings)
- `alembic/versions/0002_seed_settings.py` — seed ค่าเริ่มต้น 6 รายการ
  (max_items_per_request=5, max_active_requests_per_student=2, max_loan_days_durable=7,
   max_renew_count=1, max_renew_days=7, due_soon_notify_days_before=2)

**auth_service.py — implement ครบทุก function**
- `register()` — เพิ่มสร้าง AuthToken (secrets.token_urlsafe) + ส่งอีเมลยืนยัน
- `verify_email()` — ตรวจ expires_at, ตั้ง email_verified=True, บันทึก used_at
- `refresh_token()` — decode JWT, ตรวจ type=="refresh", คืน access token ใหม่
- `forgot_password()` — สร้าง token + ส่งอีเมล, silent return ป้องกัน user enumeration
- `reset_password()` — ตรวจ token, hash password ใหม่

**borrow_service.py — implement ครบทุก function**
- `create_request()` — ตรวจ max_active quota, ตรวจ max_items, ตรวจ stock ทุกรายการก่อน insert, แจ้ง admin ทุกคน
- `approve_request()` — ลด quantity_available, consumable auto-return (returned=True ทันที), คำนวณ due_date, แจ้งนักศึกษา
- `reject_request()` — เปลี่ยน status + rejection_reason + แจ้งนักศึกษา
- `renew_item()` — ตรวจ renewed_count < max_renew_count, ต่อ extended_due_date
- `return_item()` — บันทึก condition_on_return, คืน stock ถ้า ok, auto-complete request ถ้าครบทุก item
- `list_requests()` — pagination + filter status/overdue, student เห็นแค่ของตัวเอง
- `send_manual_reminder()` — admin ส่ง in_app reminder

**scheduler.py — implement notification jobs**
- `_check_due_soon()` — แจ้งเตือน student รายการครบกำหนดตาม due_soon_notify_days_before
- `_check_overdue()` — ตั้ง is_overdue=True + แจ้ง student และ admin ทุกคน

**main.py — bugfix**
- เพิ่ม `os.makedirs(settings.UPLOAD_DIR, exist_ok=True)` ก่อน mount StaticFiles
  (แก้ RuntimeError crash ถ้าโฟลเดอร์ uploads ยังไม่มี)

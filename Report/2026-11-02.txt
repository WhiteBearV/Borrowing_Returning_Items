  - `users_service.attach_study_year()` + ตัวกรอง `list_users(year_group=...)` ใช้ฟังก์ชันนี้ → ป้ายเป็น "บุคลากร" ไม่ใช่ "ไม่ทราบชั้นปี"

  - `dashboard_service.get_summary()` นับอาจารย์กลุ่มนี้เป็นบุคลากร ไม่ปนในการ์ดชั้นปี/สาขาของนักศึกษา
- **ระงับการยืมเมื่อค่าปรับค้างชำระ ≥ 200 บาท**
  - migration `0050_fine_block_threshold.py` เพิ่ม setting `fine_block_threshold` = 200 (0 = ไม่ระงับ, superadmin เท่านั้น)
  - `settings_service._validate_setting_value()` ห้ามค่าติดลบ
  - `users_service.attach_unpaid_fines()` เติม `fine_blocked` + `fine_block_threshold` (query ยอดค้างเดิมจุดเดียว)
  - `borrow_service.create_request()` ปฏิเสธ 403 พร้อมยอดค้างและให้ติดต่อเจ้าหน้าที่ (เจ้าหน้าที่ไม่ติด เหมือนโควตา)
  - `schemas/user.py::UserResponse` เพิ่ม 2 ฟิลด์ → `/users/me` ส่งให้หน้าเว็บ
- เทสใหม่ `tests/test_fine_block_and_teacher.py` (2 เทส) · รวมทั้งชุด **503 passed** · `alembic check` ไม่มีส่วนต่าง

## สถานะโดยรวม

**Backend:** ~98% — ฟีเจอร์ตามแผนครบ เหลือ Web Push, .ics, ค้นหาด้วยรูป (งานใหม่)

**ระยะรวม:** ระบบหลักใช้งานจริงแล้ว (v2.1 บน VM) · ช่วงนี้เป็นงานเสริมตาม feedback ผู้ใช้ + รายงานโครงงาน

งานที่เหลือเรียงจากเบาไปหนัก: ลบ venv เก่า → ทดสอบหน้าเว็บ → deploy → แนบ .ics → อัปเดตเอกสาร/สไลด์ →
backup off-site → ค้นหาด้วยรูป (3–4 วัน) → รายงานโครงงาน → Web Push (หนักสุด ติด cert self-signed + iPhone ต้องเป็น PWA)

## หมายเหตุ / ความเสี่ยง ⚠️

- deploy รอบหน้ามี migration (0050) ต้องใช้ขั้นตอนเต็ม ไม่ใช่อัปเดตเล็ก `--no-deps`
- ค้นหาด้วยรูปทำให้ image backend ใหญ่ขึ้น ~1 GB และใช้ RAM เพิ่ม ~1 GB — ต้องเช็คสเปก VM ก่อน
- Web Push ต้องใช้โดเมน + cert ที่เบราว์เซอร์เชื่อถือ (self-signed ใช้ service worker ไม่ได้) ต้องคุยกับคณะ

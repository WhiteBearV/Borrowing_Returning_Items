# มาตรฐานการตั้งชื่ออุปกรณ์

> feedback อาจารย์ที่ปรึกษา 5 ก.ย. 2569 ข้อ 18 — *"เห็นชื่อ DHT11 แล้วไม่รู้ว่าคืออะไร"*
> เอกสารนี้คือกฎที่ตกลงกันแล้ว ใช้ตอนเพิ่มของใหม่และตอนไล่แก้ของเดิม

---

## 1. ปัญหาที่แก้

ของเดิมในคลังจำนวนมากเอา **ชื่อรุ่น** มาเป็น **ชื่อสินค้า** เช่น `DHT11`, `LM35`, `L298N`
ผลคือ:

- นักศึกษาที่ยังไม่รู้จักรุ่น ค้นคำว่า "เซ็นเซอร์ความชื้น" แล้ว**ไม่เจอ**
- `DHT11` กับ `DHT12` ดูเหมือนของคนละอย่างที่ไม่เกี่ยวกัน ทั้งที่เป็นตระกูลเดียวกัน
- คนกรอกข้อมูลสับสนระหว่าง **รุ่น / ซีเรียล / รหัสทะเบียน** เพราะไม่มีช่องแยกให้

## 2. ของ 4 อย่างที่ต้องแยกจากกัน

| สิ่งที่เก็บ | คอลัมน์ | ซ้ำกันได้ไหม | ใครเป็นคนกำหนด | ตัวอย่าง |
|---|---|---|---|---|
| **ชื่ออุปกรณ์** — ป้ายให้คนอ่านเข้าใจทันที | `name` | ซ้ำได้ (ของรุ่นเดียวกันชื่อเหมือนกัน) | เรา | `เซ็นเซอร์อุณหภูมิและความชื้น DHT11` |
| **รุ่น** — เหมือนกันทุกชิ้นของรุ่นนั้น | `model_number` | ซ้ำได้ | ผู้ผลิต | `DHT11` |
| **ซีเรียล (SN)** — ไม่ซ้ำรายชิ้น | `serial_number` | **ห้ามซ้ำ** | ผู้ผลิต | `CN0X8H2K` |
| **รหัสทะเบียน** — เลขครุภัณฑ์/รหัสวัสดุ | `code` | **ห้ามซ้ำ** | ระบบ/งานพัสดุ | `740-011-0001-63` |

> ระบบค้นหาครอบคลุมทั้ง 4 ช่อง (`equipment_service._search_clause`) — พิมพ์อะไรที่รู้ก็เจอ

## 3. สูตรตั้งชื่อ

```
[ประเภทของ]  [คุณสมบัติ/สิ่งที่วัดหรือทำ]  [รุ่น]
```

ไล่จาก **กว้าง → แคบ** เสมอ (Noun → Modifier → Attribute) เพื่อให้ของประเภทเดียวกันเรียงติดกันในรายการ

| ❌ อย่าตั้งแบบนี้ | ✅ ตั้งแบบนี้ |
|---|---|
| `DHT11` | `เซ็นเซอร์อุณหภูมิและความชื้น DHT11` |
| `L298N` | `บอร์ดขับมอเตอร์ L298N` |
| `Notebook Dell` | `โน้ตบุ๊ค Dell Latitude 5400` |
| `สาย USB` | `สาย USB-A เป็น USB-C ยาว 1 ม.` |
| `มัลติมิเตอร์ (ตัวใหม่)` | `มัลติมิเตอร์ดิจิทัล Fluke 115` |

**กฎย่อย**
- ใช้ภาษาไทยเป็นหลักสำหรับคำที่คนค้นจริง ("เซ็นเซอร์" ไม่ใช่ "Sensor") — ชื่อรุ่นคงภาษาอังกฤษตามผู้ผลิต
- ห้ามใส่สถานะ/ตำแหน่ง/เจ้าของลงในชื่อ (`(ตัวใหม่)`, `(ห้อง 15310)`, `ของอาจารย์…`) — มีคอลัมน์ของมันอยู่แล้ว
- ห้ามใส่จำนวนลงในชื่อ (`สายไฟ 10 เส้น`) — จำนวนอยู่ที่ `quantity_total`
- ห้ามใช้ `_` หรืออักขระพิเศษเพื่อคั่นคำ ใช้เว้นวรรคปกติ
- ชื่อเดียวกัน = ระบบถือว่าเป็น "รุ่นเดียวกัน" และยุบเป็นการ์ดเดียวในหน้ารายการ (`find_group_members` จับกลุ่มด้วยชื่อ)
  → **ของคนละรุ่นต้องชื่อไม่เหมือนกัน** ไม่งั้นสต็อกจะถูกนับรวมผิดกลุ่ม

## 4. ที่มา (ค้นไว้ตอนวางแผน 5 ก.ย. 69)

- [FTMaintenance — Asset Naming Conventions](https://ftmaintenance.com/maintenance-management/asset-naming-convention-complete-guide/) — สูตร Noun, Modifier, Attribute
- [Tractian — Asset Naming Convention](https://tractian.com/en/glossary/asset-naming-convention) — "ชื่อ" กับ "รหัส" คนละหน้าที่ ต้องมีทั้งคู่
- [Limble — 11 Asset Naming Best Practices](https://limble.com/learn/asset-maintenance/naming-convention/) — สม่ำเสมอ · ห้ามอักขระพิเศษ · เขียนกฎเป็นเอกสาร
- [eCl@ss / UNSPSC](https://www.anglera.com/glossary/eclass-classification) — ของอิเล็กทรอนิกส์พึ่งหมวดหมู่ + attribute ไม่ใช่ชื่อล้วน
- [ITAM naming conventions](https://blog.invgate.com/naming-conventions) — ตัดสินใจรูปแบบก่อนพิมพ์ป้ายใบแรก

## 5. งานที่ยังค้าง (ข้อมูล ไม่ใช่โค้ด)

ของเดิมในคลังที่ชื่อเป็นชื่อรุ่นล้วนยังไม่ได้ไล่แก้ — ใช้ **"แก้ไขหลายรายการ"** ในหน้าจัดการอุปกรณ์
(มีช่อง *ชื่ออุปกรณ์ · ผู้ผลิต · รุ่น* ให้แก้ทีละหลายแถวได้) ทำทีละหมวดตามลำดับความถี่ในการยืม
